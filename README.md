# AI-Fraud-Detection-System

Real-time AI-powered fraud detection system that combines machine learning, computer vision, and gesture recognition to simulate intelligent financial transaction monitoring.

The system analyzes transaction data using an Isolation Forest model and detects anomalies based on time and amount features. It also integrates real-time webcam-based hand tracking using MediaPipe to control the system through gestures.

This project demonstrates how AI can be used in fintech security systems for real-time fraud detection, visualization, and interactive control.
